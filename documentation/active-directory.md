# Active Directory Configuration

## Overview

Active Directory Domain Services (AD DS) was configured on Windows Server 2019 to simulate an enterprise domain environment.

This setup allowed centralized authentication, user management, and policy enforcement for the SOC Home Lab.

---

## Lab Environment

| Component | Details |
|----------|---------|
| Operating System | Windows Server 2019 |
| Role | Domain Controller |
| Directory Service | Active Directory Domain Services (AD DS) |
| Client | Windows 11 |

---

## Configuration Tasks

- Installed Active Directory Domain Services
- Promoted the server as a Domain Controller
- Created a new domain
- Created Organizational Units (OUs)
- Added user accounts
- Added security groups
- Joined the Windows 11 endpoint to the domain
