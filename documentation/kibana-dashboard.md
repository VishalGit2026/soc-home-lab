# Kibana Dashboard

## Overview

A custom Kibana dashboard was created to monitor Windows Security Events collected through Wazuh SIEM.

The dashboard provides centralized visibility into authentication events, account management, and endpoint activities.

---

## Dashboard Panels

| Visualization | Purpose |
|--------------|---------|
| Successful Logins (4624) | Monitor successful user logins |
| Failed Logins (4625) | Detect authentication failures |
| User Account Created (4720) | Monitor newly created accounts |
| User Added to Privileged Group (4732) | Detect privilege escalation |
| Top Users | Identify most active user accounts |
| Top Hosts | Monitor endpoint activity |
