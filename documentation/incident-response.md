# Incident Response

## Overview

Incident Response is the structured process of identifying, investigating, containing, and recovering from security incidents.

This document describes the incident response workflow followed in the Enterprise SOC Home Lab.

---

## Incident Response Lifecycle

1. Detection
2. Analysis
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

---

## Detection Sources

- Wazuh SIEM Alerts
- Windows Security Event Logs
- Sysmon Events
- Kibana Dashboard

---

## Investigation Process

- Review Wazuh alerts
- Verify Windows Event IDs
- Analyze Sysmon events
- Correlate related logs
- Identify affected endpoint
- Determine attack timeline

---

## Recovery Actions

- Isolate affected endpoint
- Remove malicious process
- Verify system integrity
- Restore normal operations

---
